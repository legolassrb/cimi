# Diagrams

- `architecture.md` — single canonical whole-app diagram, overwritten on each update to reflect current reality (or, pre-implementation, clearly labeled as planned/target architecture).
- `features/<slug>.md` — one file per feature, updated in place whenever that feature is next worked on. Not exhaustive for every feature — only for whichever feature(s) were most recently touched.

Generated and maintained by the `diagram-mapper` agent (`.claude/agents/diagram-mapper.md`).
