# Worklogs

One file per recap, named `YYYY-MM-DD-HHMM.md`. Each file recaps everything done since the previous file's checkpoint (see its `Covers commits:` footer) — concise, technical entries for a 10y-SWE audience, not narrative status updates.

Generated and maintained by the `worklog-recorder` agent (`.claude/agents/worklog-recorder.md`). Don't hand-edit past entries; if something needs correcting, note it in the next entry.
